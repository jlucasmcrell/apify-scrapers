{%- comment -%} Traffic measurement. OFF unless _config.yml sets analytics.provider. Why this file exists: the site had no analytics of any kind (checked live 2026-09-18 - no GA, Plausible, Umami, PostHog, Matomo, Fathom, Cloudflare or Segment). The only observable was Apify-side run counts, which is the right outcome metric and a useless diagnostic one: a visit from the n8n template gallery, a Hugging Face dataset card or a Google result looked exactly like nobody arriving at all. Nothing is collected until a provider and id are set. All three supported options are cookie-less and store no personal data, so no consent banner is required. Pick one and set both keys; no other change needed. goatcounter : free for personal/non-commercial use. id = your subdomain. https://www.goatcounter.com plausible : paid hosted (or self-hosted). id = the domain, e.g. apify.revenuesystemslabs.com. https://plausible.io umami : free tier hosted. id = the website UUID. https://umami.is {%- endcomment -%} {%- assign a = site.analytics -%} {%- assign prov = a.provider | default: "" | strip -%} {%- assign ident = a.id | default: "" | strip -%} {%- comment -%} An empty string is TRUTHY in Liquid (only nil and false are falsy), so the guard must compare against "" explicitly. The first version of this file tested `if a and a.provider and a.id`, which was true for the empty config, fell into a case that matched no `when`, and silently emitted nothing at all - an off switch that also disabled the off state. {%- endcomment -%} {%- if prov != "" and ident != "" -%} {%- case prov -%} {%- when "goatcounter" -%} {%- when "plausible" -%} {%- when "umami" -%} {%- endcase -%} {%- else -%} {%- endif -%}
